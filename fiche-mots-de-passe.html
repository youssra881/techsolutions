Comment connaître le mot de passe ?

Le mot de passe n'est pas retrouvé dans phpMyAdmin. La base contient une empreinte, par exemple $2y$10$....

PHP utilise password_verify() pour comparer le mot de passe tapé avec cette empreinte.

Résultat vrai : la connexion fonctionne. Résultat faux : le site affiche « Identifiant ou mot de passe incorrect ».

Pourquoi ces mots de passe ?

Ce sont les mots de passe de test donnés dans les consignes du cours :

  • Admin2026 pour Martin Durand.
  • Salarie2026 pour tous les autres comptes.

Dans phpMyAdmin, ils ne sont pas écrits en clair : seuls les résultats d'password_hash() sont enregistrés.

Comment se connecter

  1. Ouvre la page de connexion.
  2. Écris un identifiant dans le premier champ.
  3. Écris le mot de passe dans le second champ.
  4. Clique sur Se connecter.

Pour tester une autre personne, clique d'abord sur Se déconnecter si une session est déjà ouverte.
